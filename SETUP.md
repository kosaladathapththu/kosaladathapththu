# Setup

1. Open your special GitHub profile repository: `kosaladathapththu/kosaladathapththu`.
2. Replace the current `README.md` with the new `README.md` from this folder.
3. Upload the complete `assets` folder.
4. Upload `.github/workflows/snake.yml` using the same folder structure.
5. Commit the changes to the `main` branch.
6. Open the **Actions** tab and run **Generate contribution snake** once.
7. Refresh your GitHub profile after the workflow finishes.

## Important

- Keep the filenames unchanged because the README uses relative paths.
- The animated photo is stored inside `assets/profile-orbit.svg`; the supplied PNG is also included as a backup.
- GitHub may cache SVG files. A new animation can take a few minutes to appear after a commit.
